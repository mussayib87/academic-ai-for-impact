# Assignments and Submissions

Teachers create, edit, publish, archive, and duplicate assignments. Records store course/section, due/start times, marks, allowed extensions, upload-size limits, and instructions. Creation enrolls the matching section or all current students and creates in-app assignment notifications.

Students can view only published assignments available to their linked student account. Upload uses random server-generated storage names, student-specific directories, configured byte-size limits, extension allowlists, and version records. The server does not execute submitted files.

Assignments authored against the official subject catalog retain a subject foreign key and are filterable by subject. Current assignment creation and grading are capped at 25 marks. Students may upload multiple allowed files as page images in one submission; each file is a separately addressable version with page number/count metadata. Teacher roster rows derive uploaded/not-submitted state from actual enrollment and stored submission records.

Teachers can inspect submission status, pending students, files, and versions; preview is restricted to PDF, common raster images, and plain text. Other files download as attachments. Numeric grades or validated rubric criteria are persisted with feedback; rubric totals are calculated from criterion scores. Grading creates an in-app notification.
